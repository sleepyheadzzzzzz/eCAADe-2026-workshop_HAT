# Environment preparation

Complete these checks before the workshop:

1. Read [`Workshop_Setup_Guide_EN.md`](Workshop_Setup_Guide_EN.md).
2. Open [`Environment_Check.ipynb`](Environment_Check.ipynb) in Google Colab
   and run all cells.
3. Use the files in [`environment/`](environment/) only when a local Python
   3.11 fallback is needed.

The environment check reports `READY`, `READY WITH WARNINGS`, or `NOT READY`.
Keep the final report when asking the tutors for technical support.
